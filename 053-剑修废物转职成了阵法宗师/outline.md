# 《剑修废物转职成了阵法宗师》

## 一句话卖点
剑气尽废的外门弟子楚陌觉醒阵纹识海，转职阵道后专克剑修傲骨，用一座座大阵打脸唯剑独尊的宗门与盟会。

## 题材与主爽点
- 题材：仙侠转职
- 主爽点：阵道碾压 / 转职逆袭 / 以静制动打脸
- 核心情绪：被贬废物的憋屈 → 阵成剑折的痛快 → 阵宗正统复兴的期待满足

## 故事背景
青霄剑宗屹立东海三百年，门规第一句便是剑为正道、阵为杂役。内门以剑意论资排辈，守阵、修阵基、养阵奴的弟子永无开峰资格，甚至不得在议事堂落座。坊间传言：宁做剑宗一条狗，不做阵奴一座碑。楚陌曾是外门最有望一剑入内的苗子，试剑台上被天才师兄厉寒以切磋为名震断剑脉，经脉寸断，剑气永绝。宗门公示天赋已尽，把他踢去守废弃外阵，与阵奴同吃霉米，雨夜还要跪在剑碑下听内门弟子训话。一个雷暴夜他跌入上古阵基裂缝，识海被亿万阵纹灌入——阵纹识海觉醒：能看见天地灵气的阵列纹理与阵眼强弱，手绘阵基可借地势、借器物、甚至借敌手剑意反噬本人。剑宗上下笑他剑废学阵丢人添丑，直到散修破山门那日，他改线残阵，让一群金丹剑修在困剑纹里自斩剑意，山门第一次靠杂役保住。

## 核心叙事
开端是废剑、守杂役阵、被内门当狗使唤。金手指亮相于山门被袭：三才困剑阵拖住入侵者，宗门被迫承认阵也能救命，随即功狗长老把他派去资源枯竭的外峰送死镇守。他反手把外峰炼成阵法试验场，收拢被剑修欺压的杂役与炼器徒，用峰阵换灵石、换口碑，路过商队愿意多付阵道过路费。中段宗门大比明文禁止非剑道参赛，他打剑阵合一擦边球登台，当众折断厉寒本命剑意，舆论撕裂剑宗上下。上宗万剑盟视阵道复兴为威胁，派出剑使灭他的阵脉传承，扬言阵兴则剑耻。终局对决指向万剑盟主司空斩与上古封剑大阵的钥匙：楚陌以阵道证明万剑亦在阵中，夺回被埋没的阵宗正统，抉择是留在剑宗当附庸还是开山自立。仇敌落幕，阵宗旌旗再起。

## 金手指与规则
- 能力：阵纹识海——透视灵气纹理、瞬识阵眼、改良残阵；高等级可布人阵，借万千剑意反噬持剑者。
- 限制/代价：布阵需材料、时间与地势；识海过载会暂时失明甚至神魂撕裂；无剑气，近身无阵则极弱；阵成前是活靶子。
- 升级路径：杂役残阵 → 峰阵 → 山门大阵 → 域阵 → 上古封剑阵。
- 不可破规则：不能无中生有灵气；违背天地阵理的强行连线会自溃；识海不直接修复剑修根基；以阵虐杀无辜会污染识海清明。

## 主要人物
### 主角
- 楚陌：隐忍缜密、记忆超强，短板是武力真空与必须向剑宗证明的执念；成长弧是放下证明欲，成为不依附剑宗的阵道宗师。

### 核心对手（1–2）
- 师兄厉寒：废其剑脉的直接仇人，大比舞台翻车，剑意被阵纹反噬成笑柄。
- 万剑盟主司空斩：打压阵道百年的霸权象征，终局败于封剑阵反噬，盟威尽丧。

### 关键配角（2–3）
- 杂役少女小篆：阵基绘图与材料采购助力，后期成长为阵图苗子。
- 退休阵奴老周：对照阵道被踩三百年的血泪，提供上古阵谱残页。
- 内门剑姬白姝：先鄙后敬，反转帮他钻大比规则空子并带来内门情报。

## 冲突网络
- 纵：阵道楚陌 vs 剑道霸权（厉寒到司空斩）
- 横：宗门资源配额、参赛资格、杂役身份尊严、上古传承归属
- 交叉：外峰试验 → 宗门大比 → 万剑盟域战

## 阶段大纲（5阶段）
**一·废剑守阵**：试剑废脉与山门遭袭；改阵退敌初显威；钩为外峰送死任命。
**二·外峰试验场**：资源断供、巡查羞辱；峰阵成型反杀巡查队；钩为大比禁令颁布。
**三·剑阵擦边**：规则战与舆论战；折断厉寒剑意；钩为万剑盟剑使入境。
**四·阵脉追杀**：传承争夺、域阵护峰；钩为封剑阵钥匙现世。
**五·封剑之战**：盟主对决；阵克万剑；仇敌落幕，开山自立阵宗收束。
