# 《我在宫里当了女帝的军师》

## 一句话卖点
落魄书生苏砚凭局势沙盘异能入宫，成为女帝身侧军师，专把权臣的杀局翻成对方的葬身之所。

## 题材与主爽点
- 题材：架空权谋
- 主爽点：智斗 / 布局打脸 / 君臣破局
- 核心情绪：朝堂碾压的憋屈 → 一计翻盘的爽 → 君臣共定天下的期待满足

## 故事背景
大瑾王朝女帝姬昭以旁支入继，朝堂被顾命三公与边镇军阀架空，宫中私下称她垂帘木偶，连用印都要首辅点头。苏砚本是落榜书生，因一篇边镇虚饷疏被权臣诬为妖言惑众，押入天牢等死，同牢犯人劝他求饶认疯。牢中他梦见沙盘：每枚棋子是人，连线是利害——局势沙盘觉醒，可在脑中推演朝局三到七步的高概率走向，但每次深推都会流鼻血、丢短时记忆。女帝微服查狱，听他一语点破三公争的不是权，是漕运，破格赦他为秘书省走马。从此他在刀尖上当军师：表面低声下气，暗中把每一次朝会变成陷阱拆除演练。宫墙内外都有刀，他的沙盘却告诉他：刀也可以被算计。

## 核心叙事
开局天牢赐死在即，女帝夜审，他用沙盘指出三公明日逼宫的三种脚本，助姬昭反将一军，把逼宫变成请罪。金手指亮相于朝会：他递的无害折子实为利害连锁，权臣签字即入套，漕运印缓缓回到御前。他助女帝先夺漕运、再削藩镇虚饷，每一次胜利都伴随宦官与外戚的反扑，沙盘里的红线越来越多。中段边镇联军以清君侧围京，沙盘出现大片迷雾——有人在故意制造不可推演的混沌。终局对决指向顾命首辅谢桓与暗中的前朝余孽暗帝：苏砚用空城与真假诏书链，把围京之局翻成勤王，并面对女帝是否还需要军师的权力终考。仇敌落幕，君臣共治新章开启。

宫墙外的茶馆里，说书人已把女帝与走马军师编成段子，有人骂他妖人，有人盼他再出一计。苏砚清楚沙盘不是天命，只是把已知信息推到极限；真正难的是让女帝在胜利后仍愿意听劝，而不是变成新的独断者。他开始在推演里给自己也标红：若君不听，臣当如何退。

边报一日三至，沙盘上的迷雾却像被人刻意泼墨。苏砚开始收集不可推演之事的共性：凡迷雾起处，必有人在销毁账册、调换人质、或散布互相矛盾的圣旨传言。

他知道自己随时可能被弃子。

## 金手指与规则
- 能力：局势沙盘——推演人物利害与朝局三到七步高概率分支；可标记必败节点。
- 限制/代价：深推伤身失忆；信息不全则沙盘迷雾；无法推演纯随机与超自然；推演结果非绝对预言。
- 升级路径：牢狱一隅 → 朝会局 → 边镇军局 → 天下势局。
- 不可破规则：沙盘不直接给人武力；故意隐瞒关键信息会反噬准确度；不能替他人注定死亡，只能标概率。

## 主要人物
### 主角
- 苏砚：冷静、嘴毒、怕死但更怕无知，短板是体质弱与政治洁癖；成长弧是从求生军师到敢与帝共担污名的国士。

### 核心对手（1–2）
- 顾命首辅谢桓：逼宫高手，阶段翻车于漕运局与签字入套。
- 前朝余孽暗帝：终局混沌制造者，败于真假诏书链。

### 关键配角（2–3）
- 女帝姬昭：不是花瓶，决策者与对照权力的孤独。
- 侍卫统领沈烈：武力执行，忠心变数。
- 史官少女柳竹：记录与舆论，反转泄露关键档案。

## 冲突网络
- 纵：苏砚与女帝 vs 顾命集团与暗帝
- 横：漕运、兵权、诏书合法性、后宫同盟
- 交叉：天牢 → 朝堂 → 围京大战

## 阶段大纲（5阶段）
**一·天牢沙盘**：赐死与夜审；一语破逼宫脚本；钩为入宫走马任命。
**二·漕运翻盘**：三公夺漕；折子入套打脸；钩为边镇暗中结盟。
**三·虚饷削藩**：清君侧舆论战；沙盘迷雾初现；钩为围京在即。
**四·围京之局**：空城与勤王连锁；首辅落败；钩为暗帝现身。
**五·诏书终考**：真假诏链破暗帝；君臣权力终考；主线收束于共治新章。
