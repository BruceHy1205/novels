# 《丧尸潮里我养出了机械军团》

## 一句话卖点
废品站技工韩铁觉醒废铁活化，在丧尸潮里把垃圾焊成机械军团，用科技火力碾压尸潮与吃人的人。

## 题材与主爽点
- 题材：末世机甲
- 主爽点：科技碾压 / 军团升级 / 火力打脸
- 核心情绪：逃命绝望 → 机甲成型的爽 → 军团破局的期待满足

## 故事背景
病毒七日席卷全国，城市沦陷，幸存者据点靠冷兵器与少量热武苦撑，子弹比罐头还珍贵。韩铁是工业园区废品站技工，懂焊接与拆解，却被据点领袖当成只会修锅的废人，分配去尸潮边缘捡零件，美其名曰贡献。一次被尸群包围，他摸到报废机械臂，臂居然听令抬起砸碎头颅——废铁活化觉醒：可与废弃机械建立共鸣，短时驱动、改造、联网成简易军团，消耗的是他的体温与神经负荷。据点贵族嘲笑铁疙瘩能打过变异体，直到他的半成品机甲一炮轰开尸墙，救下被献祭出城的老人小孩。从此有人叫他铁老爷，有人要收编他，有人要砸毁一切非生物武装。韩铁只想先把人带走，把枪口对准真正该打的东西。

## 核心叙事
开局被派去送死捡荒，机械臂认主，硬生生杀出尸群。他在废弃工厂建秘密车间，用尸潮间隙焊出盾卫、炮台与侦察蛛，第一次用火力线守住一条撤离走廊。据点领袖丘成要收编军团充作私兵，他拒绝后遭背叛，差点被当诱饵扔出城墙。中段出现高智慧变异体与净化教会——教会视机械为异端，要砸毁一切非生物武装，甚至与变异体达成诡异默契。韩铁联合其他技工与被压迫的拾荒者，把工厂升级成移动堡垒。终局对决指向教会背后的生科财阀：病毒与选择性救灾同源，方舟只给人上人。他率机械军团撕开财阀方舟，把真相与生存权抢回人手。仇敌落幕，机械与人如何共治成新命题。

工厂夜里电焊的蓝光成了幸存者的灯塔，也成了教会点名的罪证。韩铁给每台机器起名，不是矫情，是提醒自己：军团听令，但人不该被当成零件。当第一批孩子躲进装甲车厢里睡觉，他才承认自己已经不只是修锅的，而是一条机械路线的带头人。

当电磁干扰让半个军团跪地起不来，韩铁第一次体会到技术路线的脆弱。他学会给关键节点留人工备份，也学会在开枪前问一句：对面是尸，还是还没变的人。

## 金手指与规则
- 能力：废铁活化——共鸣驱动废弃机械、联网成军团、现场改装武器平台。
- 限制/代价：消耗体温与神经，过载会瘫痪；精密芯片稀缺；电磁风暴区失灵；对完全活体生物无直接控制。
- 升级路径：单臂 → 班组机甲 → 工厂军团 → 移动堡垒 → 城级战争机械。
- 不可破规则：无材料不能空造；活化不轻易赋予永久自我意识；故意屠戮无辜幸存者会遭共鸣反噬失控。

## 主要人物
### 主角
- 韩铁：手巧、寡言、护短，短板是不善权谋与社交；成长弧是从修锅匠到机械领主，学会带人而不只带机器。

### 核心对手（1–2）
- 据点领袖丘成：剥削献祭型管理者，阶段翻车于背叛败露与机甲镇压。
- 净化教会与财阀代理人：终局对手，败于方舟被撕与真相广播。

### 关键配角（2–3）
- 小焊工苗苗：技术助手，成长对照。
- 前军人萧北：战术补足，先疑后服。
- 医生洛安：道德锚点，反转揭露病毒人为痕迹。

## 冲突网络
- 纵：韩铁机械路线 vs 尸潮、教会、财阀
- 横：零件资源、据点话语权、科技伦理、幸存者归属
- 交叉：废品站 → 工厂堡垒 → 方舟战场

## 阶段大纲（5阶段）
**一·废铁认主**：送死捡荒；机械臂突围；钩为据点要收编军团。
**二·秘密车间**：焊出班组机甲；打脸贵族质疑；钩为丘成背叛献祭。
**三·教会砸机**：异端审判与电磁干扰；移动堡垒成型；钩为财阀方舟坐标泄露。
**四·联军北上**：多据点技工同盟；智慧尸潮拦路；钩为病毒真相证据。
**五·撕方舟**：终局火力碾压；仇敌落幕；机械与人共治新命题。
